# Schwa: food & beverage — audio

British English voice. One mp3 per line, saved as <key>.mp3 into

    GB/pronunciation/schwa/assets/audio/

LOWERCASE 'pronunciation'. GitHub Pages is case-sensitive: a folder named
'Pronunciation' with a capital P is a different URL and will 404 silently.

The key is generated by the module: lowercase, apostrophes dropped, every
other run of non-alphanumerics collapsed to a single hyphen. Do not rename
the files by hand — the page looks them up by that exact key.

The page tries GB first, then the older geii collection, then the browser
voice. Nothing has to be registered anywhere: drop an mp3 in and it plays.
